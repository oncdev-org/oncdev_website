Настройка на смартфонах

Дата обновления: 29 июня 2026 г.
Компьютеры (Windows)

Шаг 1a: Клиент для Android

Для Android рекомендуется установить приложение v2rayTun из Google Play. Если оно недоступно, вы можете использовать Happ, v2rayNG или любые их аналоги.
Установить v2rayTun

Шаг 1b: Клиент для iOS

Для устройств Apple (iPhone/iPad) подходят приложения V2Box, Happ, v2rayTun или Streisand. Все они бесплатно доступны в App Store. Дальнейший процесс настройки для iOS и Android полностью идентичен.

1

Установка клиента

Установите выбранное приложение (например, v2rayTun) на свой смартфон по ссылкам выше.

Установите приложение
2

Копирование ссылки подписки

Скопируйте ссылку на вашу личную подписку, которую вам выдали после оформления покупки. Она имеет следующий формат: https://oncdev.duckdns.org:8012/sub/<ВАШ_УНИКАЛЬНЫЙ_КОД>

https://oncdev.duckdns.org:8012/...
3

Импорт в приложение

Запустите приложение v2rayTun. Найдите и нажмите на круглую кнопку со знаком плюс +, которая расположена в правом верхнем углу главного экрана.

v2rayTun
+
Список пуст.
Нажмите на плюс вверху.
4

Импорт из буфера обмена

В открывшемся контекстном меню выберите пункт "Импорт из буфера обмена" (Import from clipboard). Ваша ссылка подписки будет автоматически добавлена в приложение.

v2rayTun
+
Добавить конфигурацию
Сканировать QR-код
Импорт из буфера
5

Выбор локации и запуск

После импорта у вас отобразится список доступных стран и серверов.

  1. Кликните по локации, к которой вы хотите подключиться (например, Netherlands).
  2. Нажмите на большую кнопку включения питания (круглая кнопка по центру).
При первом запуске операционная система смартфона может запросить разрешение на создание VPN-соединения — подтвердите его нажатием «ОК» или «Разрешить».

v2rayTun
+
Подключено
Доступные локации
🇳🇱 Netherlands (NL)
🇩🇪 Germany (DE)
🇺🇸 United States (US)
